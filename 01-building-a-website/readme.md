# A Computational Design Project Archive

# Project Ideas

## Concept

A restrained project-archive webpage for Computational Design Practices. The object presents a single academic project through a small hierarchy of metadata, writing, and one JavaScript interaction.

## Object Direction

The project can function as a modular archive structure in which each computational-design exercise becomes a similarly restrained record.

The emphasis is on consistency, readability, and documentation rather than on turning the archive into an interactive application.

## Spatial Experience

A three-part header places the institution at left, the course and archive identity in the center, and an About link at right.

The main content is organized as a narrow reading column containing the year, title, author, advisor, Abstract, Motivation, Methodology, and Interactive Demo.

## Interaction

The central interaction is intentionally small: a single button demonstrates JavaScript event handling and provides a brief response without changing the basic reading experience.

# Digital Objects

## Digital Object

The digital object consists of an academic project record, a structured written statement, and a small browser interaction.

The written material remains the primary content, while the interaction provides a minimal computational element that distinguishes the page from a purely static document.

## Content Structure

The archive record is organized around project metadata and explanatory writing:

- Year
- Project title
- Author
- Advisor
- Abstract
- Motivation
- Methodology
- Interactive Demo

This structure creates a consistent format that can be extended to additional projects within the archive.

## Spatial Composition

The page uses a narrow reading column to establish a clear editorial hierarchy. The header provides global orientation while the project record remains the visual focus.

Generous spacing separates metadata, section headings, and body text so the page can be read as documentation rather than as a dense information panel.

# Aesthetic

## Visual Language

The page uses a narrow reading column to establish a clear editorial hierarchy. The header provides global orientation while the project record remains the visual focus.

Generous spacing separates metadata, section headings, and body text so the page can be read as documentation rather than as a dense information panel.

### Color Palette

A blue-to-pale-green vertical gradient forms the main color field.

Dark near-black text provides contrast, while light gray dividers separate sections without creating strong visual boundaries.

The palette should remain quiet enough for the written content to remain primary.

### Typography

Roboto is used throughout the page.

Hierarchy comes from weight, size, uppercase section labels, spacing, and alignment rather than decorative typography.

The typographic system should make the archive feel consistent and institutional while remaining contemporary.

## Layout

The three-part header establishes the archive context without taking significant vertical space.

The narrow central reading column creates a focused reading experience and allows the project record to maintain a clear hierarchy from metadata through longer written sections.

The Interactive Demo should appear as part of the project record rather than as a separate application-like interface.

## Interaction

The demo button provides the main interactive moment.

Its response should be immediate and legible, but intentionally limited in scope. The interaction demonstrates that the archive can contain computational behavior without allowing that behavior to overwhelm the academic documentation.

## Atmosphere

The object should feel precise, quiet, and editorial rather than immersive or theatrical.

Its digital character comes from the gradient, spacing, typography, and small computational interaction rather than from animation or visual effects.

## Website Components

### HTML

The HTML establishes the archive as a structured academic document.

It contains the three-part header, project metadata, written sections, and Interactive Demo while maintaining a clear hierarchy between navigation, project information, and content.

### CSS

The CSS establishes the blue-to-pale-green gradient, typography, spacing, dividers, reading column, header alignment, and interaction states.

The styling should remain restrained and consistent so that the archive can accommodate additional project records without requiring a new visual system for each one.
